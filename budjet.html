Smart command format

Title amount @date #category !wallet. Prefix expenses with −, income with +, and transfers with =, e.g. Move savings =500 @today !cash >bank %1.08. The amount uses the linked wallet's currency. The rate multiplies the source amount to get the destination amount. If omitted, the rate is derived from the saved USD rates.

Dates: @today, @yesterday, @tomorrow, @2026-10-14. Wallet references use lowercase names with hyphens, e.g. !daily-cash. Valid command parts appear as badges below the input.
